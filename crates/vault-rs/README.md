# vault-rs

A UNIX-friendly PKI certificate management tool for HashiCorp Vault, built on the
[`vault-session`](https://crates.io/crates/vault-session) crate for address discovery, login and
token handling. See the [repository README](https://github.com/ticpu/vault-rs) for usage,
installation and the full command reference.
